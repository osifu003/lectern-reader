    Natural voices · Google

    How to get a key
    1. Open aistudio.google.com/apikey, sign in and create an API key. That key works with the Gemini speech models, including Flash-Lite, and reads scanned pages.
    2. Paste the key above and press Save. The app lists the speech models your key offers and picks the cheapest.
    3. Optional: for Chirp 3 HD as well, enable the Cloud Text-to-Speech API in the same Google Cloud project.

    The key is kept only in this browser and is sent only to Google. Usage beyond Google’s free allowance is billed to the key’s project; see Google’s pricing.

    Sync across devices · Google Drive

    Set up sync (one time)

    Sync signs in with a Google client ID that belongs to you, so nobody else's server is involved. Make it once on a computer:

    1. Open console.cloud.google.com and create a project named Lectern.
    2. In APIs & Services › Library, find Google Drive API and press Enable.
    3. Open Google Auth Platform and press Get started. App name Lectern, your Gmail as support and contact email, Audience External. Under Audience, add your Gmail as a test user.
    4. Under Clients, create a client of type Web application. Add https://osifu003.github.io under Authorized JavaScript origins and https://osifu003.github.io/lectern-reader/ under Authorized redirect URIs.
    5. Copy the Client ID it shows, paste it here, press Save, then Sign in with Google. Do the same on each device, or have the ID built into the app.

    Books, chapters and reading positions go to a hidden folder in your own Google Drive that only Lectern can open. Saved audio, your API key and display settings stay on each device. Signing in lasts about an hour at a time; after that the app asks you to reconnect, and changes made meanwhile are kept and sent then.
